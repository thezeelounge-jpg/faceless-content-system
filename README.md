# Creator Tool

Realistic digital-twin reels for creators who don't want to film, with full QA on every video.

- **Start here:** [START-HERE.md](START-HERE.md) covers setup, keys, costs and safety.
- **Build prompts:** [PROMPTS.md](PROMPTS.md) has one per phase.
- **Specs:** [docs/PRODUCT.md](docs/PRODUCT.md), [docs/QA-SPEC.md](docs/QA-SPEC.md), [docs/RECORDING-GUIDE.md](docs/RECORDING-GUIDE.md)
- **Rules for Claude Code:** [CLAUDE.md](CLAUDE.md)

## Everyday commands

| Command | What it does |
|---|---|
| `npm run dev` | Runs the app at http://localhost:3000 |
| `npm run trigger:dev` | Runs background jobs on your laptop (keep it open in a second window) |
| `npm test` | Runs the automated tests |
| `npm run lint` / `npm run typecheck` | Checks the code |
| `npm run db:push` | Sends database changes to Supabase |

On your laptop, http://localhost:3000/setup shows which keys are filled in.
